ГЛАВНОЕ ПРАВИЛО ТЕРМИНОЛОГИИ НА ЗАЩИТЕ:
Никогда не называй %d, %c, %f «указателями»! В Си указатели — это совсем другая тема (int *p).
Значки с процентом называются СПЕЦИФИКАТОРАМИ ФОРМАТА (или управляющими символами формата).

1. Заголовочные файлы и старт программы (строки 1–15)

#include <stdio.h>
#include <limits.h>
#include <float.h>
#include <windows.h>
  • # — знак директивы препроцессора. Это команда, которая срабатывает ДО того, как компилятор начнёт переводить код в машинный вид.
  • include — буквально «включить/вставить сюда содержимое файла».
  • <stdio.h> (Standard Input/Output Header) — заголовочный файл стандартного ввода-вывода. Без него компилятор не знает, что такое printf и scanf.
  • <limits.h> — файл с готовыми константами минимальных и максимальных значений для целых типов (CHAR_MIN, CHAR_MAX, UCHAR_MAX, INT_MIN, INT_MAX, UINT_MAX).
  • <float.h> — файл с границами для вещественных (дробных) типов (FLT_MIN, FLT_MAX, DBL_MIN, DBL_MAX).
  • <windows.h> — системный заголовочный файл Windows API. Подключён только ради двух строчек ниже, которые чинят русский шрифт в консоли.
int main() {
  • main() — главная функция, точка входа. Операционная система всегда запускает программу ровно с первой строчки внутри main.
  • int перед main — тип возвращаемого значения. Означает, что при закрытии программа вернёт системе целое число (код завершения).
  • { — открывающая фигурная скобка, начало тела функции main.
SetConsoleCP(CP_UTF8);
SetConsoleOutputCP(CP_UTF8);
  • По умолчанию терминал Windows работает в старой кодировке (CP866 / CP1251), а наш файл main.c сохранён в современной кодировке UTF-8.
  • SetConsoleCP(CP_UTF8) — переключает ввод с клавиатуры в UTF-8.
  • SetConsoleOutputCP(CP_UTF8) — переключает вывод на экран в UTF-8 (кодовая страница 65001), чтобы кириллица печаталась нормальными буквами, а не «кракозябрами».
  • ; (точка с запятой) — обязательный разделитель инструкций в языке Си (означает конец команды).
printf("Студент: Чнаваян Адриан | Группа: М03-104БВ-26 | Вариант: 29 ");
  • printf(...) — функция форматного вывода текста в консоль (Print Formatted).
  • — управляющая последовательность (escape-последовательность) переноса строки (New Line). Без следующий printf начнёт печатать прямо встык на той же строке.

2. Задание 1 — Ввод, эхопечать, форматы, системы счисления, sizeof()

char c_val;
int i_val;
float f_val;
double d_val;
  • Объявление четырёх переменных базовых типов — процессор выделяет под них ячейки в оперативной памяти:
  • char c_val; — символьный тип, занимает 1 байт (8 бит). Хранит ASCII-код одного символа.
  • int i_val; — целочисленный тип со знаком, занимает 4 байта (32 бита).
  • float f_val; — вещественный (дробный) тип одинарной точности, занимает 4 байта (32 бита), хранит ~6–7 точных значащих цифр.
  • double d_val; — вещественный тип двойной точности, занимает 8 байт (64 бита), хранит ~15–16 точных значащих цифр.
printf("Введите символ (char): ");
scanf(" %c", &c_val);
printf("Эхопечать char: %c ", c_val);
  • scanf(...) — функция форматного ввода с клавиатуры (Scan Formatted).
  • Микро-деталь №1 — ПРОБЕЛ перед %c (" %c"): Если пользователь перед этим вводил число и нажал Enter, в буфере ввода остаётся символ . Без пробела scanf("%c") моментально проглотит этот Enter и пропустит ввод символа! Пробел заставляет scanf пропустить все невидимые пробелы и переносы строк.
  • Микро-деталь №2 — АМПЕРСАНД & перед c_val (&c_val): Это операция взятия адреса переменной в оперативной памяти. Функции scanf нужно положить введённое значение прямо в ячейку памяти, поэтому ей передаётся адрес ячейки, а не само значение.
  • Эхопечать: сразу после scanf вызываем printf с тем же спецификатором %c (уже БЕЗ &, так как printf нужно только прочитать значение), чтобы убедиться, что программа считала всё верно.
scanf("%d", &i_val);
scanf("%f", &f_val);
scanf("%lf", &d_val);
  • %d — считывает целое десятичное число (decimal) в 4-байтную ячейку int.
  • %f — считывает дробное число в 4-байтную ячейку float.
  • %lf (Long Float) — считывает дробное число в 8-байтную ячейку double. Ловушка: если в scanf для double написать просто %f вместо %lf, запишутся только 4 байта из 8, и в переменной окажется мусор!
printf("char=[%4c] | int=[%8d] | float=[%10.2f] | double=[%12.4lf] ", c_val, i_val, f_val, d_val);
  • Пункт 1.2: вывод всех 4 значений одним оператором printf с управлением шириной поля и точностью:
  • %4c — выделяет под символ поле шириной минимум в 4 знакоместа (слева добавятся 3 пробела, выравнивание по правому краю).
  • %8d — выделяет под целое число поле шириной минимум в 8 знакомест (например, число 29 выведется как " 29"). Если число длиннее 8 символов — оно напечатается целиком, ничего не обрежется.
  • %10.2f — число ДО точки (10) задаёт общую ширину поля (включая саму точку и цифры после неё), а число ПОСЛЕ точки (2) задаёт количество знаков после запятой (округляет до сотых).
  • %12.4lf — общая ширина поля 12 позиций, 4 знака после запятой.
  • Квадратные скобки [...] в строке поставлены специально для наглядности, чтобы преподаватель сразу видел границы выделенных полей и пробелы выравнивания!
printf("char: символ='%c', dec=%d, oct=%o, hex=%X ",
c_val, (unsigned char)c_val, (unsigned char)c_val, (unsigned char)c_val);
printf("int: dec=%d, oct=%o, hex=%X ", i_val, i_val, i_val);
printf("float: exp=%e ", f_val);
printf("double: exp=%e ", d_val);
  • Пункт 1.3: в памяти число хранится в двоичном виде, а спецификаторы просто отображают его в разных системах счисления:
  • %c — выводит символ из таблицы ASCII.
  • %d — выводит код в десятичной системе со знаком (Decimal).
  • %o — выводит в восьмеричной системе (Octal, цифры 0–7).
  • %X — выводит в шестнадцатеричной системе (Hexadecimal, цифры 0–9 и заглавные буквы A–F; маленькая %x вывела бы строчные a–f).
  • Зачем написано (unsigned char)c_val? Это явное приведение типа. Если ввести русскую букву или символ с кодом > 127, знаковый char сочтёт его отрицательным, и %o / %X распечатают его как огромное 4-байтное число (FFFFFF...). Приведение к (unsigned char) гарантирует аккуратный 1-байтный код от 0 до 255.
  • %e — выводит дробное число в экспоненциальной (научной) форме: мантисса с одной цифрой до точки и степень десятки (например, 1.250000e+02 означает 1.25 × 102 = 125).
printf("sizeof(char) = %zu байт ", sizeof(char));
  • sizeof(тип) — это унарная операция (не функция!), которая возвращает размер типа данных или переменной в байтах. Вычисляется ещё на этапе компиляции.
  • %zu — специальный беззнаковый спецификатор формата для типа size_t, который возвращает оператор sizeof.

3. Задание 2 — Предельные значения из <limits.h> и <float.h>

printf("CHAR_MIN = %d CHAR_MAX = %d ", CHAR_MIN, CHAR_MAX);
printf("UCHAR_MAX = %u ", UCHAR_MAX);
printf("INT_MIN = %d INT_MAX = %d ", INT_MIN, INT_MAX);
printf("UINT_MAX = %u ", UINT_MAX);
printf("FLT_MIN = %e FLT_MAX = %e ", FLT_MIN, FLT_MAX);
printf("DBL_MIN = %e DBL_MAX = %e ", DBL_MIN, DBL_MAX);
  • — символ горизонтальной табуляции (как клавиша Tab), выравнивает второй столбец.
  • CHAR_MIN (-128) и CHAR_MAX (127) — границы знакового 1-байтного char (от -27 до 27 - 1). Выводим через %d.
  • UCHAR_MAX (255) — максимум беззнакового unsigned char (28 - 1). Минимум у беззнаковых всегда 0. Выводим через %u (unsigned).
  • INT_MIN (-2147483648) и INT_MAX (2147483647) — границы 4-байтного знакового int (от -231 до 231 - 1).
  • UINT_MAX (4294967295) — максимум 4-байтного беззнакового unsigned int (232 - 1). Важно: выводить строго через %u! Если написать %d, то 4294967295 выведется как -1.
  • FLT_MIN / FLT_MAX (~1.17e-38 ... 3.40e+38) и DBL_MIN / DBL_MAX (~2.22e-308 ... 1.79e+308) — минимальное положительное нормализованное и максимальное значения для float и double.

4. Задание 3 — Цепочки преобразований (расширение и усечение)

char c3; short int s3; int i3;
unsigned char uc3; unsigned short int us3; unsigned int ui3;
  • Создаём 6 переменных: 3 знаковых (1, 2 и 4 байта) и 3 беззнаковых (1, 2 и 4 байта).
c3 = CHAR_MAX; s3 = c3; i3 = s3;
printf("char -> short -> int: %d -> %d -> %d ", c3, s3, i3);
  • Расширение типа (от меньшего к большему: 1 байт → 2 байта → 4 байта):
  • Значение перекладывается по цепочке слева направо. Так как ячейка становится шире, число помещается целиком без потерь (127 → 127 → 127).
  • Для отрицательного CHAR_MIN = -128 (в двоичном виде 10000000) при расширении до 2 и 4 байт срабатывает знаковое расширение: пустые левые байты заполняются единицами (11111111 10000000), чтобы сохранить отрицательное значение -128 в дополнительном коде.
i3 = INT_MAX; s3 = i3; c3 = s3;
printf("int -> short -> char: %d -> %d -> %d ", i3, s3, c3);
  • Сужение / усечение типа (от большего к меньшему: 4 байта → 2 байта → 1 байт):
  • Когда мы присваиваем 4-байтное число в 2-байтный short, процессор просто отрезает 2 старших (левых) байта и оставляет только 2 младших (правых). Затем при присваивании в 1-байтный char отрезается ещё один байт — остаётся только самый правый байт.
  • У INT_MAX = 2147483647 в двоичном виде 01111111 11111111 11111111 11111111. Отрезали левые байты → осталось 11111111. Так как char знаковый, а самый левый бит равен 1, в дополнительном коде это число равно -1!
i3 = 483; s3 = i3; c3 = s3;
printf("int(483) -> short -> char: %d -> %d -> %d ", i3, s3, c3);
  • Пример из методички (483 → 483 → -29):
  • Число 483 в 2 байтах (short) = 00000001 11100011 (влезло полностью).
  • Перекладываем в 1 байт (char): левый байт 00000001 отбрасывается, остаётся 11100011.
  • Как перевести 11100011 в десятичное число: левый бит 1 → число отрицательное. Инвертируем биты: 00011100 (это 16 + 8 + 4 = 28). Прибавляем 1: 28 + 1 = 29. Ставим минус → -29.
i3 = -300; s3 = i3; c3 = s3;
  • Отрицательный int (-300 → -300 → -44):
  • 300 в 2 байтах = 00000001 00101100. Переводим -300 в дополнительный код (инверсия + 1): 11111110 11010100.
  • Отрезаем левый байт при записи в char → остаётся 11010100.
  • Переводим обратно: инверсия 00101011 (43) + 1 = 44 → -44.

5. Задание 4 — Переполнение границ и завершение (строки 130–153)

int s_max = INT_MAX; s_max = s_max + 1;
unsigned int u_max = UINT_MAX; u_max = u_max + 1;
int s_min = INT_MIN; s_min = s_min - 1;
unsigned int u_min = 0; u_min = u_min - 1;
  • INT_MAX + 1: 01111111...1111 + 1 = 10000000...0000. Единица попадает в знаковый (31-й) бит, и максимальное положительное число 2147483647 скачком превращается в -2147483648 (INT_MIN). (Примечание для отличников: по стандарту языка Си знаковое переполнение является неопределённым поведением — Undefined Behavior, но на процессорах x86 в дополнительном коде оно работает именно так).
  • UINT_MAX + 1: 11111111...1111 + 1 = 1 00000000...0000. Возникает перенос в 33-й бит, который не влезает в 4 байта и отбрасывается — остаётся 0.
  • INT_MIN - 1: из 10000000...0000 вычитаем 1 и получаем 01111111...1111 — скачок обратно в 2147483647.
  • 0 - 1 (для unsigned int): заём из старшего разряда превращает все 32 бита в единицы (1111...1111) — получаем 4294967295 (UINT_MAX).
return 0;
}
  • return 0; — завершает работу функции main и возвращает операционной системе код 0 (сигнал того, что программа отработала штатно и без ошибок).
  • } — закрывающая фигурная скобка, конец программы.
Короткий чек-лист перед самым ответом преподавателю:
  1. Значки %d, %c, %lf называй спецификаторами формата.
  2. Зачем пробел перед %c в scanf(" %c", &c_val)? — Чтобы пропустить символ переноса строки , оставшийся в буфере клавиатуры.
  3. Зачем & в scanf? — Чтобы передать адрес переменной в памяти, куда нужно записать введённое число.
  4. Что происходит при сужении типа (int → char)? — Усечение (отбрасывание) старших байтов; если старший бит оставшегося байта равен 1, знаковый тип читает число как отрицательное в дополнительном коде.
