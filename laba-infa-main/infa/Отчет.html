2. Обязательное бинарное доказательство для Задания 3 (побайтовое расположение)

3. Объяснение результатов Задания 4 (Переполнение)

Операция Результат Почему так происходит на уровне бит
INT_MAX + 1 2147483647 → -2147483648 01111111...1111 + 1 = 10000000...0000. Единица перешла в знаковый (31-й) бит — число стало самым маленьким отрицательным (INT_MIN).
UINT_MAX + 1 4294967295 → 0 11111111...1111 + 1 = 1 00000000...0000. 33-й бит переноса отбрасывается, остаются все нули.
INT_MIN - 1 -2147483648 → 2147483647 10000000...0000 - 1 = 01111111...1111 (обратный переход в INT_MAX).
0u - 1 0 → 4294967295 При вычитании 1 из беззнакового нуля происходит заём из несуществующего 33-го бита, все 32 бита становятся единицами (UINT_MAX).
